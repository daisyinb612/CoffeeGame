# 冰美式互动短剧 Demo

《冰美式制作》使用 10 分钟原片，从原片 00:07.5 开始播放，跳过按手表和口头喊「开始」的片头。共 41 个互动节点。开头完整播放老师的器具示范，约 00:39 才出现第一关的回顾题。到达关键时间点时，题目和选项叠在当前画面。答对后从同一位置继续播放，答错后留在该处看提示并重试。搅拌段支持触屏滑动、鼠标拖动和点按替代。

首页只显示竖屏短剧。题目、选项、提示和播放按钮都在画面内。原声字幕默认显示，互动题出现时暂时隐藏。原来的分步练习可直接打开 `practice.html`。

第一关是器具多选。学习者找齐刚才准备的玻璃杯、量杯、搅拌棒和吸管后，确认并继续播放。

## 本地运行

在项目根目录执行以下命令。需要 Python 3 和 FFmpeg。素材生成命令用于分步练习和短剧封面。已有封面时，可直接运行本地服务器。

```sh
python3 demo/build_media.py
python3 demo/build_media.py --story
python3 demo/serve.py
```

打开 [本地短剧](http://127.0.0.1:8765/)。课程素材从本地读取。

## 调整课程

在 `story.js` 中用原片秒数设置节点。每条的 `ref` 对应[动作时间索引](../docs/video-timeline.json)里的段号。该索引来自复核后的 `final.reviewed.json`。节点从动作段中挑选，暂停点结合关键画面与字幕空档调整。题目有时在动作前让玩家决定，有时在动作已入镜后辨认。量杯和搅拌棒分别有准备、使用和收尾节点。冲煮头空排水结合原声讲解出题。成品检查、客人接杯、服务微笑和电子秤最终归位缺少清楚画面。短剧由 `serve.py` 读取 `source/冰美式第一人称视频.MP4`，按原始字节播放。原片为 HEVC，浏览器和设备需支持该编码。中文字幕在 `captions/story-zh.vtt`，来自同一条原片的逐句音频转写。

保留原片先备杯具、后洗手的拍摄顺序。[原片复核](../docs/video-review-2026-11-20.md)记录了它与参考流程的差异。

分步练习版的片段配置在 `lesson.json`，互动配置在 `game.js`。修改素材区间后重新运行相应的素材生成命令。

## 设计依据

第一人称视频分步示范来自一项由 4 名孤独症青少年参加的餐食制作研究。课程采用这个思路来组织实拍素材，互动题、原声和播放节奏仍需请实际学习者试用。 [第一人称视频示范与视频提示对比研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7070110/)

固定每一步的页面结构，提供具体简短的指令和可重复的示范。默认静音，使用者自行开始播放和进入下一步。 [W3C 认知无障碍设计指南](https://www.w3.org/TR/coga-usable/)
