# 冰美式互动短剧 · V1 运行与维护

《冰美式制作》从原片 00:07.5 开始，按拍摄顺序连续播放。准备阶段的四关依次是认器具与吸管、准备量杯和搅拌棒、洗杯与擦干、洗手与擦手。每关在相应动作示范后暂停，答完从暂停处继续。洗手和器具准备都在取冰、取粉前完成。后续保留原有的取冰、制作、出品和清洁节点。搅拌段支持触屏滑动、鼠标拖动和点按替代。

首页只显示竖屏短剧。题目、选项、提示和播放按钮都在画面内。原声字幕默认显示，互动题出现时暂时隐藏。原来的分步练习可直接打开 `practice.html`。

第一关用六张实拍卡片回顾器具。每次显示一件，在照片下方选择「没有」或「有」，判断刚才的准备阶段是否拿取或摆放过它。六张答完后确认吸管放在温杯区。第四关选对擦手用的灰布后，视频继续播放到取冰段。

六件器具都可以直接拖动旋转，松手即停。模型根据原片估算比例。量杯使用原片带深色短柄的款式，托盘和吸管也按原片外观制作。浏览器无法渲染 3D 时，使用 `assets/inventory/` 内的原片截图。`assets/preparation/` 的白色口布和灰色抹布来自《咖啡学本 2.0》PDF 第 18 页，其余为原片截图。

第 5 关是冰杯小游戏。原片连续播完取冰、接水和放杯，在 03:04.7 暂停。玩家用同一只玻璃杯加冰、接水，再检查并清理台面的碎冰和水迹，最后把杯子放好备用。直接点冰铲或把它拖到杯口就能加冰。点画面里的水龙头开关接水，再点一次关水。每个步骤确认后才判断，冰量或水位偏多偏少时可重试。浏览器无法显示 3D 时使用三道图像练习。

第 6–10 关练习清洁粉碗、去皮与称粉、布粉、压粉和清理残粉。第 7 关在 3D 台面上拖动手柄，在电子秤上去皮，到磨豆机点按或长按接粉，再放回秤上看读数。17.8–18.2 g（含边界）可以通过。转两圈布粉、压一次和用后归位在同一段互动里完成。

第 11–13 关练习空排水与擦拭、量杯去皮与就位、挂手柄与萃取。第 14 关是 3D 调配与搅拌实操（2 分）。07:08 调配示范结束后，把浓缩液量杯拖到冰水杯口，倒入时不能外洒；随后在杯中滑动搅匀，再把使用后的搅拌棒拖进水槽。点按器具也可完成相同步骤，方便键盘和辅助技术使用。

右上角「设置」里可以打开「关卡选择」，按流程分组查看全部 19 关。第 17 关在生成的未清洁工作区画面中多选需要清洁的对象，统一检查并提供两级提示；通过后直接进入第 18 关四组用布配对，第 19 关通过位置图片三选一练习工具归位，答对后点击「下一步」继续。选中一关可直接定位到该题。

## 本地运行

在项目根目录运行服务。需要 Python 3，原片路径见[素材说明](../source/README.md)。

```sh
python3 demo/serve.py
```

打开 [本地短剧](http://127.0.0.1:8765/)。需要重新生成封面时运行 `python3 demo/build_media.py --story`；需要运行旧分步练习时，先运行 `python3 demo/build_media.py` 生成练习片段。这两条生成命令都需要 FFmpeg。

## 调整课程

在 [story.js](story.js) 查看关卡。列表位置决定编号，`at` 是相对原片起点的秒数，`ref` 对应[动作时间索引](../docs/video-timeline.json)，`phase` 对应 [drama.js](drama.js) 的选关分组，`game` 对应具体玩法。`choices` 或 `rounds` 用于选择题，`null` 标记正确选项。调整暂停点时要一起核对[字幕](captions/story-zh.vtt)和[原片复核](../docs/video-review-2026-11-20.md)。第 16 关在服务原声示范之前暂停，让玩家先练表达。 支持录音练习，参考用语可通过「看看怎么说」展开；录音后可以回听、重录，再继续观看原片示范。录音通过浏览器麦克风权限获取，仅保留在当前关卡页面，离开后清除。第 16 关聚焦口头表达，不显示成品预览。

准备阶段的暂停点约为 00:39、01:29、01:47 和 02:14。字幕按原片时间显示。[原片复核](../docs/video-review-2026-11-20.md)记录了各动作的顺序。

分步练习版的片段配置在 `lesson.json`，互动配置在 `game.js`。修改素材区间后重新运行相应的素材生成命令。

## 设计依据

第一人称视频分步示范来自一项由 4 名孤独症青少年参加的餐食制作研究。课程采用这个思路来组织实拍素材，互动题、原声和播放节奏仍需请实际学习者试用。 [第一人称视频示范与视频提示对比研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7070110/)

固定每一步的页面结构，提供具体简短的指令和可重复的示范。默认静音，使用者自行开始播放和进入下一步。 [W3C 认知无障碍设计指南](https://www.w3.org/TR/coga-usable/)

本轮调整详见[2026-11-25 交互与 UI 修改说明](../docs/ui-changes-2026-11-25.md)。
