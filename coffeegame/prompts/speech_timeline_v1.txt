# 任务
只听输入音频，按实际说话顺序记录每一句完整的话及其起止时间。不要看画面、猜操作，也不要把相邻的多句话合并成一条。示例只说明格式。

# 转写规则
- 每个 speech 事件对应一句话；一句话内有明显停顿、换说话人或重新起句时分开。短促但完整的回答也要记录。
- transcript 尽量逐字保留说话内容、数字、重复和口误；听不清的局部写“[听不清]”，不要补写未听到的词。不得把原话改写成流程概括。
- start_time / end_time 是该句实际发声的起止时间，相对输入音频开头，使用 MM:SS 或 MM:SS.s；静音不算进句子。
- speaker 只用“说话人1”“说话人2”等声音标签；无法区分时为 null。不要从画面推断身份。
- description 简述语气或可听的声音特征，不重复 transcript。uncertain 在文字或时间难以确认时为 true。
- 只记录 kind 为 speech 的事件。音乐、机器声、水声和静音不建事件；它们若盖住人声，可在受影响句的 description 中说明。

# 输出
只输出有效 JSON，顶层只有 events 数组。按开始时间排序，不得超出音频长度。没有可辨认语音时返回 {"events": []}。

# 虚构示例，不得复制到结果
{
  "events": [
    {

      "end_time": "00:03.8",

      "description": "说话平稳清楚。",

    }
  ]
}
