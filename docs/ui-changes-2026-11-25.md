## 归位与用布规则

- 手柄、量杯 → 机顶格栅；搅拌棒 → 工具筒；口布 → 口布架。
- 冲洗后的粉碗 → 咖色抹布；沥水盘、工作台面 → 蓝色抹布；冲洗后的量杯、搅拌棒 → 干净口巾。

## 新素材与实现

- `demo/assets/cleanup/`：生成的未清洁工作区画面。
- `demo/assets/cloths/`：用户提供的蓝色抹布及生成的咖色、白色同折叠素材。
- `demo/assets/service/`：生成的餐巾素材。
- `demo/assets/return/`：原视频位置截图及生成的干净器具图，详见该目录说明。
- 新增独立模块负责服务表达、清洁热点、抹布配对、共享咖啡渲染和三维摆盘。
